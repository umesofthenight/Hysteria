Honorific Names

Names used to address higher existences.

A Honorific Name is a set of stanzas describing high level beings equivalent to a Sequence 3 Beyonders or above. They are either Beyonders (opens in a new tab) or Spirits.

Description

Honorific Names can be used to contact/pray to a powerful entity, or in ritualistic magic to borrow its power. For example to ensure the effectiveness of a contract with Spirit world creature, its final part can use Death (opens in a new tab)'s Honorific Name (which can be replaced by the description of someone high in the undead domain or the Underworld itself). The Honorific Name of an Angel (opens in a new tab) or above can grant extraordinary attributes on anything it is written on, so long as its owner is still alive.

At Sequence 3, a Beyonder gains the ability to respond to prayers within a certain area by creating an honorable title that points to them. The said area can be greater depending of their pathway. Sequence 2 Beyonders and above can respond to prayers all over the world. Klein obtained this advantage earlier by tying himself to the Sefirah Castle (opens in a new tab), and he suspected that Bernadette did the same by using a Grade 0 Sealed Artifact.

Only deities can use a three-line Honorific Name, although "Their" Honorific Name often won't be limited to three lines, but when chanting or praying one could choose any three. An existence that had once accommodated the Uniqueness (opens in a new tab) of "Their" pathway can be considered half a True God and can shorten "Their" Honorific Names to three lines similar to a god's name. Once a Beyonder has successfully accommodated the Uniqueness, so long as no one has accommodated "Their" former Uniqueness, "Their" level would not drop and "Their" former Honorific Name would still point towards "Them", even if "They" have perished and become an Evil Spirit (opens in a new tab). Klein (opens in a new tab) was able to use a three-line Honorific Name for "The Fool" before he became a True Deity because he was tying himself with the Sefirah Castle (opens in a new tab).

Directly chanting the true name of a deity is normally considered an act of blasphemy, and it may result a corresponding backlash. Using "Their" true name in the presence of "Their" remnant aura can trigger unpredictable changes.

The prayer and automatic response property of an Honorific Name can be used to lock onto the position of its owner, if they are not strong enough. For this reason, for those who lack power it is better to not let anyone know their Honorific Name.

Just knowing the Honorific Name of a being can bring corruption upon oneself.

Under certain circumstances, using a vague and inaccurate Honorific Name is a way to avoid drawing the attention of the corresponding being, while borrowing a part of "Their" power. Such Honorific Names could designate several existences, for example, if they have a shared authority.

  • For example, Klein (opens in a new tab) relied on the shared authority between him and the Circle of Inevitability (opens in a new tab) to devise a vague and inaccurate Honorific Name that could refer to both of them.

The deity's name commonly referred to by the masses might be different from "Their" Honorific Name, which represents the true divine name of the deity. For example, the Circle of Inevitability (opens in a new tab) is only an abbreviation of "His" Honorific Name.

Steps to Make an Honorific Name

Each Honorific Name is unique, it reflects the personalities, experiences, and characteristics of its owner.

When one makes an Honorific Name, the most important part is to ensure that the description of the chant is directed at its owner accurately, or it could hit some other unknown existence that fits the description. Therefore the combination of several lines is needed, it makes easier to restrict the description to one person.

Only deities can have an Honorific Name that is only three-lines long, while lower existences need at least five lines.

Honorific Names can be changed at any time.
