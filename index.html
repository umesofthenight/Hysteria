FAQs

Before you join

Check the age requirement and how character approval works.

What kind of server is Hysteria?

Hysteria is a Discord roleplay server based on Lord of Mysteries. You write an original character and play alongside other members. It uses the novels' supernatural setting, including Beyonders and divination. Server lore takes priority wherever it differs from canon.

Is there a minimum age?

You must be 14 or older and meet Discord's minimum age in your country if it is higher. Roleplay may involve horror, violence, death, and psychological distress. Sexually explicit content is not allowed.

How much of the series do I need to know?

You don't need to know the whole series. Start with the Getting Started guide, then read about your character's Pathway and background. If they belong to an organization, read about that too. Staff can help with questions.

Where does roleplay take place?

Arc Zero takes place in the Loen Kingdom. The server is in Open Beta. Check the announcements in Discord for story updates and any changes to playable regions.

How do I get my character approved?

After joining the Discord server, read the rules and server systems. Reserve an available face claim, complete the character template, and submit it with the required references. Staff will review the submission and may ask for changes. Wait for approval before you roleplay.
